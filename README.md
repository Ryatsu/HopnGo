# Hop'nGo – Ride-Hailing System

## Project Overview

### Project Title

**Hop'nGo – Ride-Hailing System**

### Problem Being Addressed

Finding convenient and reliable transportation can be difficult, especially when passengers need a ride quickly. At the same time, drivers need an organized way to receive ride requests and manage their trips.

Hop'nGo aims to address these problems by providing a ride-hailing system that connects passengers with available drivers. The system manages the ride process from booking and driver acceptance to trip completion and payment.

### Target Users / Stakeholders

* **Passenger** – Uses the system to request rides, view ride information, cancel trips, and make payments.
* **Driver** – Uses the system to receive and accept ride requests, manage trips, and complete rides.
* **System Administrator** – Manages users, rides, and other system-related information.

### System Objectives

The main objective of Hop'nGo is to provide a simple and organized ride-hailing platform that connects passengers with drivers.

The system aims to:

* Allow passengers to conveniently book a ride.
* Match passengers with available drivers.
* Allow drivers to accept and manage ride requests.
* Manage the complete trip from start to completion.
* Calculate and process ride payments.
* Maintain organized records of users, rides, locations, and payments.
* Provide a clear and efficient workflow for both passengers and drivers.

### Major Features / Modules

#### 1. User Management

* User registration and login
* Passenger and driver profiles
* User information management

#### 2. Ride Booking

* Enter pickup location
* Enter destination
* Request a ride
* View ride status

#### 3. Driver Matching

* Identify available drivers
* Send ride requests to drivers
* Allow drivers to accept or reject ride requests

#### 4. Trip Management

* Start a trip
* Manage trip status
* End a trip
* Cancel a trip when necessary

#### 5. Payment Management

* Calculate ride fare
* Process payments
* Record payment information and status

#### 6. System Management

* Manage users
* Manage ride records
* Manage payment records
* Monitor system activities
